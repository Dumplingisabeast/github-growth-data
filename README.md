# 📊 GitHub Growth Tracker — Weekly Data

Top 100 fastest-growing GitHub repos each week, enriched with:
- ⭐ Stars gained, total stars, forks
- 📝 AI-generated descriptions & "right for you if" summaries
- 🎥 YouTube tutorial links
- 📅 Days since launch, language, license

Data sourced from GitHub Archive via BigQuery, enriched via GitHub API + YouTube search + DeepSeek summarization.

## 📁 Structure

```
github_growth_top100_YYYYMMDD_YYYYMMDD.csv   ← Weekly top 100
weekly-synthesis/
  YYYYMMDD_YYYYMMDD.md                        ← Trend analysis
```
