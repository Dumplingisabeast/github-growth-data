# 📊 GitHub Growth Tracker — Weekly Data

Top 100 fastest-growing GitHub repos each week, enriched with metadata, YouTube tutorials, and AI insights.

Data sourced from GitHub Archive via BigQuery, enriched via GitHub API + YouTube search + DeepSeek.

## 📁 Structure

```
github_growth_full_YYYYMMDD_YYYYMMDD.csv        ← Full dataset (~1000 repos)
github_growth_top100_YYYYMMDD_YYYYMMDD.csv       ← Top 100 (enriched, from v2 pipeline)
weekly-synthesis/
  YYYYMMDD_YYYYMMDD.md                           ← Weekly trend analysis
```
